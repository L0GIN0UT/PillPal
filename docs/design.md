# Дизайн PillPal — фаза 1

Макеты (холст Claude Design, приватный — открывает владелец): https://claude.ai/artifact/1H8PxxDyC6YTwuFoUwECDb

Статус: **на ревью владельцем**. UI-код фазы 2 пишется только после утверждения.

## Дизайн-система «Абрикос»

| Токен | Значение | Назначение |
|---|---|---|
| `bg` | `#FFF7F0` | фон экранов |
| `surface` | `#FFFFFF` | карточки, поля |
| `border` | `#EADBCF` | разделители, обводки |
| `ink` | `#2B2320` | основной текст |
| `ink-muted` | `#6B5D57` | вторичный текст |
| `action` | `#C2531E` | главное действие («Принял»), белый текст 6.3:1 |
| `action-soft` | `#FCE6D6` | мягкие плашки (остаток, приглашение) |
| `taken` | `#4F7A63` | принято (шалфей) |
| `missed` | `#2F5D8A` | пропущено (синий; отличается от «принято» и тоном, и светлотой) |

Тёмная тема: фон `#1C1715`, поверхность `#2A2320`, текст `#F6EDE6`, действие `#F4A57A` с тёмным текстом, принято `#7FB79A`.

**Шрифты:** Rubik (заголовки, 500–700), Nunito (текст, 400–800). Оба с кириллицей.

**Правила:**
- Цвет всегда дублируется иконкой и подписью.
- Касания ≥ 44 px; режим для старших — шкала ×1.3, кнопки ≥ 64 px, контраст ≥ 7:1.
- Радиусы 12 / 16 / 18 / 24; отступы кратны 4.
- Реклама только на вторичных экранах (история, список лекарств); никогда на «Сегодня», напоминании и отметке приёма.

## Экраны на холсте

Сегодня · Сегодня (режим для старших, тёмная тема) · Напоминание и уровни уведомлений · Добавить лекарство (скан / справочник / вручную, подсказка о пересечении веществ, приватность) · Расписание (все типы) · Близкие (связи, подопечный профиль, приглашение по ссылке/QR) · История (календарь, % соблюдения, PDF, место баннера).
