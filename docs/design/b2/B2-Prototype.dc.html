Удалить аккаунт?

Аккаунт блокируется сразу и стирается не позднее чем через 30 дней.

  • Близкие сразу теряют доступ к вашим лекарствам.
  • Барсик: других опекунов нет, профиль сотрётся вместе с аккаунтом.
  • До стирания аккаунт можно восстановить, войдя снова.

Кликабельный сценарий

Нажимайте на кнопки в телефоне. Клик мимо подсвечивает активные места. «Назад» и «Сначала» — над телефоном.

Основной путь

  1. Добро пожаловать → Создать аккаунт → Регистрация → Продолжить
  2. Согласия: отметьте третий пункт — кнопка Создать аккаунт включится → Код из письма → Подтвердить → Сегодня
  3. Сегодня: Принял — карточка «Сейчас» переходит в «принято»; кружок у «Магний B6» тоже отмечается
  4. Лекарства: + → Эналаприл 10 мг → Расписание → Сохранить → баннер на «Лекарствах»; Сканировать — лист снизу
  5. Близкие: Мама → карточка близкого. История: Отчёт PDF — лист, Создать и отправить → баннер
  6. Сегодня: шестерёнка → Настройки: аккаунт → Смена пароля; «Согласия» → Приватность → Удалить аккаунт — диалог

Везде

  • Таб-бар: Сегодня, Лекарства, Близкие, История — короткое перекрёстное затухание
  • Стрелка «Назад», «Закрыть», тап по затемнению — шаг назад
  • «Уже есть аккаунт» → Вход → Войти → Сегодня

Движение

  • Вперёд: экран въезжает справа с лёгким проявлением, --motion-base + --ease-emphasized-decelerate; назад — уезжает вправо
  • Табы: затухание --motion-fast; листы: снизу поверх затемнения, --motion-slow; диалоги: проявление и масштаб от 0.96
  • При prefers-reduced-motion — только затухания и мгновенные смены состояний

Шестерёнка на «Сегодня» добавлена только в прототипе: на доске B-Today её нет, в приложении она есть.
