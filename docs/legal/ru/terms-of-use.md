## 4. Близкие

4.1. Пользователь может выдать другому пользователю того же региона доступ к своему профилю по
приглашению (наблюдатель, редактор, опекун) и выбрать для каждого лекарства, что видно близким.
Пользователь сам решает, кому выдавать доступ, и может отозвать его в любой момент.

4.2. Близкий, получивший доступ, обязан использовать данные только для заботы о владельце
профиля и не передавать их третьим лицам.

архива только для чтения (до 365 дней) либо удаляется, если соопекунов нет.
