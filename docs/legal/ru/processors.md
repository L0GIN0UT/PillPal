# Обработчики и третьи лица по регионам

> **ЧЕРНОВИК. Не является юридической консультацией.** Проверить у юриста до запуска.
> Источники: ADR 0008 §8, ADR 0017 §11, ADR 0018 §6 и §8, ADR 0013/0015 (сканер, справочник),
> `backend/README.md`. Регион EU — шаблон: запуск в ЕС позже.

**Хранимые данные** (база данных, Redis, резервные копии, Sentry) находятся только у
хостинг-провайдера региона, для RU — в РФ (ч. 5 ст. 18 152-ФЗ). Сервисы доставки push получают
метаданные события, которые сервер относит к медицинским: тип события (например, что по профилю
есть уведомление о пропуске приёма) и непрозрачные идентификаторы профиля и уведомления, — без
названий лекарств, доз и времени приёма. Квалификация потоков к иностранным сервисам (push, ML Kit,
App Store, Firebase SDK на устройстве) по ст. 12 152-ФЗ — `[ЗАПОЛНИТЬ: вывод юриста, страны,
уведомление РКН]`. Каждый регион имеет свои учётные записи, ключи и настройки у каждого сервиса; общих хранилищ между
регионами нет.

## Регион RU

| Лицо | Назначение | Какие данные | Где | Статус |
|---|---|---|---|---|
| `[ЗАПОЛНИТЬ: провайдер, город РФ]` | хостинг сервера, БД PostgreSQL, Redis, резервных копий | все данные аккаунтов RU, включая данные о здоровье | РФ | обработчик по поручению (ч. 3 ст. 6) |
| Собственный Sentry (self-hosted) | отчёты об ошибках | тип ошибки, стек вызовов, путь запроса без параметров, user-agent, x-request-id; без текста ошибки, тел запросов, IP и медданных | РФ, `[ЗАПОЛНИТЬ: тот же хостинг?]` | ресурс оператора |
| `[ЗАПОЛНИТЬ]` (SMTP-сервис) | служебные письма | адрес почты, язык, текст письма (коды, уведомления); без медданных | `[ЗАПОЛНИТЬ: страна]` | обработчик |
| Google (Firebase Cloud Messaging) | доставка push на Android | токен устройства, непрозрачные идентификаторы профиля и уведомления, тип события (в т. ч. пропуск приёма — медицинские метаданные) | `[ЗАПОЛНИТЬ: США? — вопрос трансграничной передачи]` | получатель |
| Google (Firebase SDK на устройстве) | регистрация устройства для push | идентификатор установки Firebase, IP-адрес устройства; запросы идут с устройства напрямую | `[ЗАПОЛНИТЬ: США? — вопрос трансграничной передачи]` | получатель |
| Apple (APNs) | доставка push на iOS | токен устройства, непрозрачные идентификаторы, тип события, ключ текста | `[ЗАПОЛНИТЬ: США? — вопрос трансграничной передачи]` | получатель |
| VK (RuStore Push) | доставка push на Android без сервисов Google | токен, непрозрачные идентификаторы, тип события | РФ | получатель |
| Google ML Kit (в составе приложения, Android; не связан с push) | распознавание штрихкода на устройстве | метрики использования сканера, отправляются с устройства напрямую; изображения и коды не передаются | `[ЗАПОЛНИТЬ: США? — вопрос трансграничной передачи]` | получатель (вопрос юристу) |
| VK ID | вход (Android), **после включения** | идентификатор у провайдера, адрес почты при наличии, временные токены обмена | РФ | получатель / источник данных |
| Яндекс ID | вход (Android), **после включения** | то же | РФ | то же |
| App Store (Apple), RuStore | покупка «без рекламы», **после включения оплаты** | платёжные данные — у магазина; оператору — товар, идентификатор покупки, даты; Apple получает сведения о покупке и псевдоним аккаунта `appAccountToken` | `[ЗАПОЛНИТЬ: App Store — США? вопрос трансграничной передачи; RuStore — РФ]` | самостоятельные операторы платежей |
| `[ЗАПОЛНИТЬ: рекламная сеть, по умолчанию Яндекс Реклама]` | баннеры на экранах «Настройки» и «О приложении», **не используется в текущей версии** | `[ЗАПОЛНИТЬ: рекламный идентификатор, данные устройства, IP]`; никаких медданных | `[ЗАПОЛНИТЬ]` | `[ЗАПОЛНИТЬ]` |
| Справочник лекарств PillPal (сервис оператора) | поиск, карточки, поиск по штрихкоду | поисковая строка или GTIN без привязки к аккаунту; IP не журналируется | `[ЗАПОЛНИТЬ: хостинг справочника]` | ресурс оператора |
| Аналитика (AppMetrica) | **не используется**; при подключении документ обновляется | — | — | — |

Не используются: sentry.io и другие облачные сервисы ошибок (сервер отказывается запускаться),
Apple Sign-In и Google Sign-In в регионе RU (сервер отказывается запускаться), Google Play
Billing в регионе RU.
